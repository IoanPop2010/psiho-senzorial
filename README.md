# Psiho Senzorial

Aplicație de învățat pentru testul de psihologie (clasa a X-a): senzații, percepții, reprezentări, plus psihicul și ipostazele lui.

Moduri: fișe, quiz, exemple pentru legi, liste de memorat, confuzii frecvente, toate definițiile.

Un singur fișier: `index.html`. Se deschide direct în browser.
